LYCEUM CLASH v2.6 — UI CLEANUP

Built from the working v2.5 multiplayer/combat build.

FIXES FROM PHONE SCREENSHOTS
- Legacy SERVER SAFE / Firebase lobby can no longer appear.
- Heroes and Shop open directly as clean loadout overlays, without the old room screen.
- New multiplayer start menu: simple CREATE / JOIN flow.
- Raw IDs such as pharaoh / school_blaster / default / focus are no longer shown as the main menu UI.
- Loadout is shown with human-readable labels.
- All menu columns/cards use equal grid widths.
- Player slots stay the same size and scroll horizontally on small phones.
- Native browser confirm dialog for “Вийти з матчу?” removed.
- Replaced with an in-game modal.
- In embedded portal mode the extra game X is hidden; the portal return control is enough.
- Long-press text selection/context menu is disabled inside battle to prevent iOS “Copy” callouts.
- Character drawing has more depth: fabric seams, hero silhouettes, face highlights, clothing texture, weapon material highlights.
- Stable Colyseus multiplayer/combat is preserved.
